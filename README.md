# Personal Portfolio Website

My personal portfolio website built with React, TypeScript, Vite, and Bootstrap.

The site highlights my software development projects, professional experience, technical interests, awards, certifications, and contact information.

## Tech Stack

* React
* TypeScript
* Vite
* Bootstrap
* CSS

## Features

* Responsive single-page layout
* Sticky navigation with smooth scrolling
* Project showcase
* Experience section
* Awards and certifications
* Contact links

## Running Locally

```bash
npm install
npm run dev
```

Then open the local Vite development URL in your browser.
